Passenger 0.2.0 runs, debugs and profiles apps made of several services, from Docker Compose, a Dockerfile or Aspire, and adds tools for web apps and their data: live requests with their SQL, EF Core migrations and configuration help. It is still free and open source under MIT, and everything this release closed is in its [0.2.0 milestone](https://github.com/Zaneris/passenger/milestone/3).

## Containers and Docker Compose

- **Run, debug, Hot Reload and profile .NET services in containers**, from a compose file, a Dockerfile or the SDK's container support: each service in a Debug tab of its own, or one service acted on while the rest run on ([#242](https://github.com/Zaneris/passenger/issues/242)).
- **The Containers window:** projects, containers, images, volumes and networks, with each one's log, stats, files and details, and a shell.
- **Code help in Dockerfiles and compose files:** checks as you type, Go to Declaration, Rename, completion, and fixes for an undeclared name or a missing connection string.
- **Add > Docker Support** and **Add > Docker Compose** write the files, backing services included; Undo takes them back.
- Works with Docker Desktop, Colima, OrbStack, Rancher Desktop, Podman or a remote engine.

## Aspire

- **Passenger is the IDE an AppHost runs under:** run, debug, Hot Reload and profile every service, with the Aspire window for its resources, consoles, logs and traces ([#243](https://github.com/Zaneris/passenger/issues/243)).
- **Code help across the AppHost:** resource names complete and lead to their declaration, Rename reaches every service, and a missing reference or parameter is fixed in place. **Add > Aspire Orchestration** adds an AppHost to a solution.

## Web apps and their data

- **Routes from code:** each web project's endpoints listed, and sent from an icon beside them ([#417](https://github.com/Zaneris/passenger/issues/417)).
- **The Requests window:** a running app's requests and the SQL each one ran, N+1s and slow queries marked ([#418](https://github.com/Zaneris/passenger/issues/418)).
- **The Migrations window:** EF Core's migrations, with whatever would stop `dotnet ef` found and fixed before it runs ([#419](https://github.com/Zaneris/passenger/issues/419)).
- **A query's SQL in the debugger** ([#420](https://github.com/Zaneris/passenger/issues/420)), and **configuration keys** completed, checked and followed to the code that reads them ([#421](https://github.com/Zaneris/passenger/issues/421)).

## Debugging

- **Several programs at once,** each in a Debug tab of its own ([#341](https://github.com/Zaneris/passenger/issues/341)).
- **The hover card opens objects and collections** ([#340](https://github.com/Zaneris/passenger/issues/340)), and Continue and the steps answer at once ([#315](https://github.com/Zaneris/passenger/issues/315)).
- **WPF's XAML Preview** draws a window as itself and runs your code in design mode ([#351](https://github.com/Zaneris/passenger/issues/351)).

## Your coding agent

- **Everything above works through MCP,** with fewer tools that each do more. `open_file`, `screenshot`, `type`, `implementations`, `debug_run_to`, `debug_set_value`, `breakpoint_remove`, `nuget_remove` and the `*_output` tools are folded into others.
- An agent asks before running code in your program or setting a breakpoint ([#278](https://github.com/Zaneris/passenger/issues/278)).

## Also new

- A VS Code keymap ([#336](https://github.com/Zaneris/passenger/issues/336)), Publish to a folder ([#337](https://github.com/Zaneris/passenger/issues/337)), and run configurations edited in place ([#230](https://github.com/Zaneris/passenger/issues/230)).
- CSV, TSV and Excel files open as tables, and images and fonts as previews.
- Ten new looks, an icon for every file, and a menu bar on Windows and Linux.
- Faster: tool windows build when first opened, and a key costs what it changed, not the file's size ([#414](https://github.com/Zaneris/passenger/issues/414)).

## Worth knowing

- Keypad keys are keys of their own in shortcuts ([#445](https://github.com/Zaneris/passenger/issues/445)), and Debug or Run of a configuration that's running restarts it.
- Windows containers aren't supported. On Podman, Dockerfiles go unchecked, since it has no BuildKit.
- Debugging or profiling in a container downloads Passenger's container tools for it once.
