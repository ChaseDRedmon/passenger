### Independently checked candidates and ordered remedy plan

- R1 — FileText.Write: fixed-name temporary file is opened with Create and follows a supplied symlink. Target canonicalization does not protect the temporary name. Use a unique same-directory name ending in SaveSuffix and CreateNew. Preserve encoding, atomic replacement, read-only checks and watcher filtering. Test through an editor save with a disposable sentinel link; existing save/history suites cover contract preservation.
- R2 — EndpointClient.SendAsync: grants distinguish authority/port while redirect forwarding compares hostname alone. Compare the full origin before forwarding headers or preserving a body. Test two isolated loopback ports, GET headers and 307 body refusal; retain relative-redirect behavior.
- R3 — Aspire StopResourceAsync: immediate runner launch refusal leaves no running process and no completion producer, but cleanup awaits Ended unconditionally. Match the existing IsRunning guard used for AppHost/session shutdown. Test failed launch through the real execution boundary; do not redefine ProcessRunner's successful-start event contract.
- R4 — DapConnection.Receive: malformed success type throws after removing the pending request; neither cancellation nor FailPending can complete it. Validate response fields before removal and treat malformed JSON/schema as a controlled connection failure. Test malformed peer replies through a real loopback stream and assert bounded request completion.
- R5 — ProfilingSession.AttachAsync: trace opening occurs after EventPipe acquisition and outside cleanup; cancellation also bypasses process disposal. Transfer ownership only after Copy succeeds; release acquired session/process on every pre-transfer failure. Test a real attachment whose trace destination cannot be created, error reporting and target survival; retain existing profile/attach smoke coverage.
- R11 — FindInFilesPopup: changing query/scope only restarts a debounce timer, so RequestReplace can combine the new query/scope with old file matches. Cancel pending work and clear replaceable results immediately when criteria change, and when an explicit refresh starts. Test a real window with an immediate scope change followed by Replace All, without waiting for the debounce.
- R12 — MarkupExtension.Read/ReadArgument: nested user markup recursively parses without a bound; background diagnostics are in the IDE process. Bound tolerant parse depth and keep an incomplete suffix rather than allow process stack exhaustion. Test a deeply nested attribute through the real XAML editor; preserve ordinary nested-extension cases. No crash threshold or performance improvement is claimed.

Independent contract challenge (`ses_e9f11806effeDPg6evC1tvSrnH`) accepted R2/R3 and refined R1/R4/R5: track temporary-file ownership before cleanup; preserve long target filenames with a short GUID basename; include malformed numeric request sequences in controlled DAP failures; preserve ProfilingException handling and nested disposal. No new stop protocol, ProcessRunner completion semantics, dependencies or abstraction layers are needed. Tests are authored at the final gate after the coherent implementation/review batch, following this environment's .NET cadence; negative controls will check the old defects where safely practical.
